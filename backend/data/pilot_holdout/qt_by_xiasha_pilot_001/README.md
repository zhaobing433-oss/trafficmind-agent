# Phase21 G3-C 钱塘试点 Hold-out / Ablation Evaluation

This pack defines the frozen G3-C hold-out evaluation for the Qiantang Baiyang-Xiasha pilot.

## Reality Boundary

- Hold-out events: synthetic validation targets, not production traffic events.
- Regional geography: G1 public-source verified pilot context.
- Knowledge: G2 public-source grounded summaries.
- Historical pool: G3-A synthetic validation history.
- Case memory: G3-B synthetic-event system-closure cases generated by the system.
- Agent provider: deterministic validation mode with `LLM_ENABLED=false`.

## Frozen T0

`2026-09-04T13:10:55Z`

All hold-out events are after this timestamp. G3-A history and G3-B case completions must remain strictly before this timestamp.

## Ablation Groups

- `A_CURRENT_EVENT_ONLY`: current event facts only.
- `B_REGIONAL`: current event plus canonical regional context.
- `C_REGION_HISTORY_KNOWLEDGE`: current event, regional context, strict-past history, and eligible knowledge.
- `D_FULL`: all of C plus strict-past validated or partial case memory.

## What This Evaluation Can Answer

1. What regional context adds to event analysis input.
2. What strict-past history plus eligible knowledge add.
3. What traceable case memory adds beyond history and knowledge.
4. Whether wrong-region, future, current-target, or ineligible knowledge leakage is absent.
5. Whether plans preserve source and grounding audit traceability.

## What This Evaluation Cannot Claim

- It cannot prove real-world traffic response effectiveness.
- It cannot benchmark live LLM quality.
- It cannot treat synthetic history as official Hangzhou traffic history.
- It cannot infer production accuracy.

## Files

- `package.json`: formal pack metadata and reality contract.
- `holdout_events.json`: frozen unseen event facts.
- `evaluation_spec.json`: frozen ablation groups and metrics.
- `evaluation_report.json`: generated deterministic evaluation report.
- `evaluation_report.md`: generated human-readable summary.
