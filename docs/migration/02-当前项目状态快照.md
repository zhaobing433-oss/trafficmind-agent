## 当前关键安全边界

- LLM 仅 **PROPOSE**（提案），不直接执行
- Compiler **确定性**编译
- Validator **fail-closed**（校验失败即拒绝）
- ToolPolicy **authoritative**（工具策略权威）
- Approval V2 使用 **exact actionStepId**
- WorkflowExecutor 是**唯一 runtime**
- UNKNOWN_OUTCOME **zero replay**（未知结果不重放）
- Semantic replan 仅 **suffix-only**（completed prefix frozen，仅重设计 unresolved suffix）
- completed 前缀 **frozen**（已完步骤不可变）
- Assessment **read-only**
